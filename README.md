# Waifu2x-Extension-GUI

### AI image and video upscaler with a user-friendly interface

Waifu2x-Extension-GUI wraps multiple AI upscaling engines in a clean graphical interface. Upscale images and videos using Waifu2x, SRMD, RealSR, and Anime4K — with GPU acceleration and batch processing.

<br>

---

## Features

| | |
|:---|:---|
| **Multiple Algorithms** | Switch between Waifu2x, SRMD, RealSR, and Anime4K per-task |
| **Image & Video** | Process both static images and video files with the same tool |
| **GPU Acceleration** | NVIDIA CUDA and AMD OpenCL support for fast processing |
| **Noise Reduction** | Built-in denoise and artifact removal for clean upscaled output |
